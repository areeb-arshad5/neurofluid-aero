# NeuroFluid-Aero: a neural operator that predicts airfoil pressure in milliseconds

**A Fourier Neural Operator (FNO) trained on 7,000+ XFOIL simulations to predict the full surface pressure distribution (Cp) of an airfoil from its shape and angle of attack, as a fast surrogate for CFD in aerodynamic design.**

![Predicted vs XFOIL pressure distributions on test airfoils](overnight/stage1_examples.png)

## Why
A single CFD run takes minutes to hours, so design optimisation that needs thousands of evaluations is slow. A trained surrogate answers in milliseconds. The catch is **trust**: does it generalise to shapes it has never seen? This project is built around measuring that honestly.

## Results so far (Stage 1, mean of 3 training seeds)
| Test set | Cp error (RMSE) | Relative error | CL error from predicted Cp |
|---|---|---|---|
| Test airfoils (families seen in training) | 0.035 | **3.8 %** | 0.0099 |
| **Unseen airfoil families** (E387, NACA 6409) | 0.146 | 18.6 % | 0.0260 |

- **19× better** than predicting the average pressure curve (Cp RMSE 0.66).
- Lift computed from the predicted Cp **beats classical ML** (random forest, gradient boosting) trained directly on lift: **1.7×** better on test airfoils and **1.7–2.8×** better on unseen families, even though the network was never trained on lift.
- **The honest gap:** error on unseen families is 4–5× higher. Closing it is the next phase (active learning on the shapes the model gets most wrong).

## Pipeline
| Phase | What | Status |
|---|---|---|
| **1. Data** | 500 airfoils generated by perturbing 15 real baselines (NACA, Eppler, Selig, RAE 2822…) in CST shape space; XFOIL at Re = 10⁶, α = −4° to 10° → **7,500 cases, 94.3 % converged**; automated QA with known-bad tests | ✅ done |
| **2. Model** | FNO trunk (4 Fourier layers, 12 modes, 2.38 M parameters) + Cp head, on a 64×64 grid encoding of the shape | ✅ done |
| **3. Training** | Leak-proof split *by airfoil*, two whole families held out; overfit-a-single-sample gate before training; 3 seeds on an RTX 4060 | ✅ Stage 1 done · all-families retrain in progress |
| 4. Validation | Active learning; higher-fidelity ANSYS Fluent tier on selected shapes | planned |
| 5. Write-up | Report and paper | planned |

![Dataset coverage: thickness vs camber of the 500 airfoils](data_generation/plots/thickness_camber_scatter.png)

## How it's kept honest
- **Splits by airfoil, not by case,** so no shape appears in both training and testing; two entire families are held out as the real generalisation test.
- **Classical baselines first,** so the neural network has to beat something meaningful.
- **Gates and tests:** the model must memorise a single sample before full training (with an lr = 0 control that must fail); 17 grid-encoding tests and 9 model tests, each with a deliberately broken case.
- **Multi-seed results:** the headline numbers are the 3-seed mean, not the luckiest run.
- The XFOIL set-up is checked on the NACA 0012 before the batch run (`data_generation/xfoil_validation/`).

## Quick start
```bash
# data (XFOIL must be on PATH)
python data_generation/generate_airfoils.py
python data_generation/run_xfoil_batch.py
python data_generation/grid_encoding.py
python data_generation/make_splits.py
# model (PyTorch, CUDA recommended)
python model/test_fno.py
python model/overfit_single_sample.py
python model/train_stage1.py --seed 42
```
Data format and contracts: `data_spec.md`. Model details: `model/README.md`.
